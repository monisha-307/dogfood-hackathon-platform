================================================================================
 F. ISSUES FOUND AND FIXED DURING THIS ACCEPTANCE PASS
================================================================================
 F1 docker-compose.yml set both `build:` and `image:`. On a fresh machine a
    plain `docker compose up` could try to pull that tag from Docker Hub
    first. The `image:` line was removed; Compose now builds when the image
    is missing (verified in C1).
 F2 /api/health did not touch the database, so it could not prove
    connectivity. It now reads the users table and returns 503 on failure.
    A plain "SELECT 1" was tried first and rejected: SQLite answers it
    without reading the database file.
 F3 The first draft of the restore instructions produced a root-owned
    database that the unprivileged app couldn't write to (HTTP 500 on the
    first write). A chown step was added and verified (C7).
 F4 DATA-MODEL.md needed import/export paths, but the app had no export.
    Added admin-only CSV and JSON export (API and UI), with CSV formula
    injection protection. Covered by 4 new tests.
